How the value is scored

implied value = TVL × category multiple × growth multiplier × maturity multiplier × chain multiplier

One function scores every protocol; no name is ever special-cased. Category multiples are stated assumptions about how each sector's token would price against TVL — capital managers and RWA price the assets they manage, plain infra prices the pipes. Implied value is this radar's own claim, never a prediction of whether or when a token launches.
