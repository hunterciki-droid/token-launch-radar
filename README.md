Token Radar ranks 198 pre-token DeFi protocols by the implied value of a future token launch, from a frozen DefiLlama snapshot, with a concrete farm plan for each one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
